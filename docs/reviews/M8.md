## Initial findings and disposition

- **P1 — parallel-channel resistance:** per-channel convection resistance was presented as whole-plate resistance. Corrected by combining equal branch resistances in parallel and treating the flow-area calibration as a whole-plate term.
- **P2 — Darcy transition discontinuity:** the Re=2300 transition used a circular-channel coefficient for a slot. Corrected to use the aspect-specific laminar coefficient at the transition.
- **P2 — outlet outside property bounds:** an outlet above the fluid table could be reported as `ok` when the mean remained in range. Corrected by checking inlet, mean, and outlet temperatures against available property bounds.
- **P2 — fractional channel count truncation:** YAML values such as 1.9 were truncated by `int()`. Corrected by passing through strict integral validation.
- **P2 — SAE30 table with absent cp/k:** requiring heat-capacity and conductivity tables rejected an otherwise usable hydraulic fluid. Corrected so hydraulic property tables remain required while unavailable thermal properties fail explicitly when requested.
