# M9 — transient thermal network implementation review

**Disposition: accepted for demonstrated capabilities.** GPT Sol's source/spec and standards correction reviews accepted the corrected M9 slice against M8 merge baseline 9503a46c92b31a393a6ee3bfa8e7f09771b8ccb8. The initial findings below were corrected before acceptance.

## Initial findings and disposition

- **P1 — B02 topology reversed:** the source table orders chip-8 elements junction-to-heatsink, while the generic Cauer builder uses reference-to-junction order. The fixture now reverses paired R/C values when constructing the chain. An independent exact response check gives a 1 W junction step rise of 0.26043605 K at 0.01 s and a DC sum of 1.126 K/W.
- **P1 — transient command unavailable:** transient-sim is now registered by the shared CLI entry point, and the shipped chip-8 example executes.
- **P2 — nonphysical coarse-grid overshoot:** implicit trapezoid on a 1 K/W, 1 J/K node with 10 W and 100 s intervals produced temperatures above and below equilibrium. The solver now propagates each piecewise-linear power segment with an exact augmented matrix exponential. Periodic simulation reuses each segment map. A one-node analytic check and same-waveform grid-refinement check pass.
- **P2 — stale conductance after mutation:** the network is now frozen after initialization, preserving consistency between its resistors and cached conductance matrix.
- **P2 — fractional cycle count truncation:** the CLI validates max_cycles as an integer before calling the solver; fractional YAML values fail with a configuration error.
- **P2 — no focused M9 acceptance tests:** added tests for B01 steady self/mutual coefficients and dynamic source superposition, B02 ladder ordering and step response, exact single-node transients, sample refinement, initial state, pulse rejection, periodic convergence/exhaustion, immutability, CLI registration and fractional cycle rejection.

## Review verification

The implementation run passed **56 focused tests** across M8/M9 liquid, fluid and CLI coverage. GPT Sol independently ran the new M9 tests and CLI checks. Ruff lint/format and scoped strict mypy passed for the M9 modules.

The B02 source fixture follows the chip-8 values in Table 3 and topology in Figs. 10 and 15(b) of [Drofenik et al., INTELEC 2003](https://www.ams-publications.ee.ethz.ch/uploads/tx_ethpublications/drofenik_INTELEC03.pdf). B01 uses the published grounded Table 1 network and fitted limits from Table 2 in [onsemi AND8215/D](https://www.onsemi.com/download/application-notes/pdf/and8215-d.pdf). For the B02 fixture, the configured reference temperature denotes the local package base/substrate boundary, not necessarily room ambient.

## Evidence limits retained

B01 steady self/mutual coefficients and B02 ladder ordering, resistance sum, and computed junction step response are checked. Digitized B01 and B02 transient source-curve comparisons remain pending; no transient source-curve parity is claimed. Package approximation offsets are kept separate from solver error. Spatial baseplate coupling is not advertised by this M9 network model.
